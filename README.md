# Portfólio — Arthur Perozin

Site pessoal em React, publicado em https://artperozin.github.io.

Baseado no template [masterPortfolio](https://github.com/ashutosh1919/masterPortfolio) (MIT), com conteúdo, textos e visual próprios.

## Rodar localmente

```bash
npm install
npm start
```

## Atualizar os projetos a partir do GitHub

```bash
GITHUB_TOKEN=<seu token> GITHUB_USERNAME=artPerozin node git_data_fetcher.mjs
```

## Publicar

```bash
npm run deploy
```

O conteúdo editável fica em `src/portfolio.js`.
